# التصميم والقرارات

**السابق:** [الدليل الرئيسي](../README.ar.md) · **الرئيسي:** [فرصة](../README.ar.md) · **التالي:** [البيانات](../data/README.ar.md)

هذه خريطة ما قررناه، وأسباب الاختيارات، وما تحققنا منه بالتنفيذ. نستخدمها للرجوع إلى التصميم وفهم كيف تطور النظام.

## ابدأ بمسودة البناء

تتابع [مسودة البناء](../fursah-ai-build-notes.md) ثماني مراحل من فهم المشكلة إلى البناء والتقييم. نحن في **المرحلة ٨**: اكتملت تجربة استرجاع صغيرة، وربطها بالتطبيق هو العمل القادم.
