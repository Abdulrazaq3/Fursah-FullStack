# الواجهة — مدخلات المستخدم والاتصال

**السابق:** [الخلفية](../backend/README.ar.md) · **الرئيسي:** [فرصة](../README.ar.md) · **التالي:** [أوامر التشغيل](../scripts/README.ar.md)

تجمع واجهة React وTypeScript معلومات المستخدم وقيوده وطلبه الحر، ثم تعرض استجابة API. تحققنا من اتصالها بالخلفية المحلية؛ تنفيذ سير التوصية داخل الخلفية هو العمل القادم.

## 1. تشغيل الواجهة

أبقِ الخادم يعمل، وافتح طرفية ثانية داخل `fursah-fullstack/frontend/`:

```bash
npm ci
cp .env.example .env
npm run dev
```

في PowerShell على Windows استخدم `Copy-Item .env.example .env`. انسخ القالب عند إعداد بيئتك المحلية لأول مرة فقط.

افتح [http://127.0.0.1:5173](http://127.0.0.1:5173). يستخدم الخادم هذا المنفذ الثابت؛ أوقف العملية المتعارضة أو غيّر المنفذ والمصادر المسموحة في الخادم عمدًا.

يحتوي `.env` على:

```dotenv
VITE_API_BASE_URL=
FURSAH_DEV_API_TARGET=http://127.0.0.1:8000
```

ترك `VITE_API_BASE_URL` فارغًا يستخدم عنوان الواجهة نفسه. يمرر Vite طلبات API محليًا، ويؤدي nginx الدور نفسه داخل الحاويات. إذا استضفت الخادم منفصلًا، عيّن أصل عنوانه الكامل دون `/api` واضبط CORS في الخلفية. أعد تشغيل Vite بعد تغيير `.env`.

## 2. ماذا تفعل الواجهة؟

1. يحدد المستخدم معلومات ملفه وقيوده.
2. تتحقق الواجهة من الاختيارات وتحفظ الملف في التخزين المحلي للمتصفح.
3. يكتب المستخدم طلب بحث حرًا.
4. يرسل `api/client.ts` الطلب إلى الخادم.
5. تعرض الواجهة التحميل أو النتائج أو المعلومات الناقصة أو عدم التطابق أو الخطأ.
6. عند فتح بطاقة، تطلب تفاصيل الفرصة من الخادم.

لا يوجد بديل يعرض بيانات وهمية. ظهور `FURSAH_NOT_IMPLEMENTED` متوقع قبل تنفيذ تمرين الخادم.

عند تغيير نص البحث أو حفظ الملف، تُلغى النتائج وطلبات البحث القديمة. لذلك لن يطبق زر حل تعارض خاص بطلب سابق على نص جديد. دون تعديل المدخلات، يُعاد إرسال نفس البحث والملف والقيود مع اختيار حل التعارض.

## 3. الملفات المهمة

| الملف | المسؤولية |
|---|---|
| `src/main.tsx` | تشغيل React وتحميل التنسيقات. |
| `src/App.tsx` | تنسيق الملف والبحث والنتائج واللوحات، وإلغاء طلبات البحث القديمة. |
| `src/types.ts` | أنواع الطلب والاستجابة الموافقة لعقد الخادم. |
| `src/api/client.ts` | HTTP والمهل والتحقق من المدخلات والاستجابات. |
| `src/labels.ts` | التسميات العربية وتنسيق التواريخ والمواعيد والتكاليف والأخطاء. |
| `src/styles.css` | التخطيط والألوان والمسافات والاستجابة لأحجام الشاشات. |
| `src/profile/choices.ts` | قوائم المدن والتخصصات والاهتمامات والمهارات في الواجهة؛ ترسل القيم المعروضة كما هي. |
| `src/profile/profile.ts` | تحميل الملف واستعادة الصالح منه وحفظه وتحويل المسودة والتحقق منها. |
| `src/profile/ProfileChoices.tsx` | القوائم والاختيار الفردي والمتعدد القابل للبحث. |
| `src/profile/ProfilePanel.tsx` | ملخص الملف ومحرره. |
| `src/opportunities/SearchForm.tsx` | إدخال البحث وإرساله. |
| `src/opportunities/SearchResults.tsx` | عرض حالة البحث الحالية. |
| `src/opportunities/OpportunityCard.tsx` | ملخص توصية وشارة الأهلية. |
| `src/opportunities/OpportunityDetails.tsx` | تحميل التفاصيل والشروط والمصادر وعرضها. |
| `src/components/Header.tsx` | الهوية البصرية وزر الملف الشخصي. |
| `src/components/Drawer.tsx` | اللوحة الجانبية المشتركة وإدارة التركيز والإغلاق. |
| `src/vite-env.d.ts` | تعريفات TypeScript لإعدادات Vite. |

ملفات مساندة:

| الملف | الهدف |
|---|---|
| `package.json` | الاعتماديات وأوامر التطوير والبناء. |
| `package-lock.json` | إصدارات دقيقة لتثبيت قابل للتكرار؛ احتفظ به. |
| `tsconfig.json` | إعداد فحص TypeScript. |
| `vite.config.ts` | إضافة React وإعداد الخادم المحلي. |
| `index.html` | نقطة دخول المتصفح وروابط الخطوط. |
| `.env.example` | قالب آمن لعنوان الخادم. |

`node_modules/` اعتماديات مثبتة، و`dist/` ناتج بناء؛ لا تعدّلهما كمصدر ولا ترفعهما إلى Git. قد تستخدم الخطوط والهوية ملفات خارجية، لكن بيانات API تأتي فقط من الخادم الذي تضبطه.

## 4. قواعد النموذج

- تختار المدن والتخصصات والاهتمامات والمهارات من `choices.ts`. الكتابة تبحث في القائمة ولا تنشئ قيمة جديدة.
- تبقى الأوصاف نصًا حرًا. لا ترسل مفاتيح النماذج من المتصفح.
- المدن المفضلة مصفوفة أو `null`، لا سلسلة نصية واحدة.
- المهارات غير المحددة تختلف عن عدم وجود مهارات صراحة وعن قائمة مهارات. يظهر «لم تُحدّد بعد» للحالة الأولى و«لا توجد — حسب اختيارك» للثانية.
- تعرض مسارات الحقول الناقصة، بما فيها أسماء المهارات ومستوياتها المفهرسة، بتسميات عربية. المسار غير المعروف يعرض طلبًا عامًا بدل النص التقني.
- الحد الأقصى للمدة عدد أيام صحيح موجب. تسمح الميزانية بالكسور لكنها لا تقبل القيم السالبة.
- تصحح الحقول المحفوظة غير الصالحة منفردة قدر الإمكان مع إبقاء الصالح وعرض إشعار. تتحول تفضيلات المدينة الواحدة القديمة إلى مصفوفات.

قيود هذه القوائم تخص الواجهة. يمكن لمستدعي API المباشر إرسال قيم نصية أخرى؛ يجب أن يتعامل تنفيذ المتدرب مع القيم غير المطابقة دون انهيار أو اختراع بديل.

## 5. توافق الطرفين

اقرأ [backend/app/schemas.py](../backend/app/schemas.py) مع [src/types.ts](src/types.ts). هذا هو عقد التكامل المقدم؛ حافظ على توافقه أثناء تعديل التنفيذ الداخلي. تغيير العقد العام يحتاج تنسيق المنظم.

ميّز بين:

- نتيجة البحث: `ok` أو `needs_info` أو `no_match` أو `error`.
- حالة التسجيل: ما يقوله المصدر عن التقديم.
- الأهلية: `confirmed` أو `uncertain` بحسب الأدلة.

تتوقع التفاصيل مدة صحيحة موجبة أو `null`، وشروطًا مجمعة تحت `mandatory` و`preferred`. يجب أن تتضمن التوصيات والتفاصيل معرفات المصادر. لا تضيف الواجهة وقت إغلاق لموعد يذكر التاريخ فقط؛ تعرض المواعيد الكاملة بتوقيت الرياض.

إذا تعذر تحميل التفاصيل الحالية، تعتبر معلومات التوصية السابقة غير متحقق منها. يبقى الخادم مسؤولًا عن اتساق حقائق التوصية والتفاصيل.

### معنى حالات البحث

| الحالة | ما يراه المستخدم | مسؤولية الخادم |
|---|---|---|
| التحميل | البحث قيد التنفيذ. | الإكمال ضمن المهلة المحددة أو إعادة خطأ مضبوط. |
| `ok` | بطاقة إلى ثلاث بطاقات توصية. | تقديم معرفات فعلية ومصادر داعمة وأهلية صادقة. |
| `needs_info` | طلب توضيح حقل قابل للتعديل أو تعارض قيود. | تحديد حقول ذات صلة دون طلب حقول غير موجودة بالنموذج. |
| `no_match` | رسالة واضحة دون بطاقات. | استخدامها عندما لا توجد نتيجة مدعومة تلبي الطلب. |
| `error` | رسالة خطأ. | إرفاق رمز الخطأ؛ الخادم غير المكتمل ليس بحثًا ناجحًا بلا نتائج. |

انسخ مثالًا من [دليل عقد الخادم](../backend/README.ar.md) إلى `/docs` لفهم الصيغة. ثم اربط بيانات فعلية، ولا تُعد المثال كتوصية وهمية.

### قيم حالة التسجيل المعروضة

الحقل `application_status` نص اختياري، وليس تعدادًا يفرض مخطط التخزين الداخلي. هذه القيم المعروفة لها تسميات عربية في الواجهة:

| قيمة API | العرض |
|---|---|
| `open` | مفتوح |
| `closed` | مغلق |
| `cancelled` | ملغى |
| `not_yet_open` | لم يبدأ التسجيل |
| `requires_verification` | يتطلب تحققًا |
| `unknown` أو `null` | غير معروف |

تقبل الواجهة أيضًا الاسم البديل `not_open_yet` بالتسمية نفسها. القيم الأخرى تعرض كما هي مع استبدال الشرطات السفلية بمسافات؛ حوّل حالاتك الداخلية عمدًا عند حدود API. هذا لا يغيّر حالات نتيجة البحث `ok` و`needs_info` و`no_match` و`error`.

عبارة منشورة «لم يبدأ التسجيل» لا تثبت الحالة الحالية بعد مرور تاريخ الفتح. احتفظ بعبارة المصدر وأضف توضيحًا أو أعد `requires_verification` عندما لا تعرف الحالة الحالية، ولا تفترض أن التسجيل مفتوح. حافظ على اتساق التوصيات والتفاصيل.

### نسخ الأدلة والحضور

تقبل التوصيات والتفاصيل `evidence_version` كنص اختياري غير فارغ. أنشئ بصمة ثابتة من حقائق المصادر، بما فيها الشروط والحضور، بترتيب ثابت. احفظ نسخة الأدلة التي جرى تقييمها للتوصية؛ لا تستبدلها بنسخة تفاصيل أحدث. قد تتغير الحقائق دون تغير معرف المصدر.

يبقى تأكيد الأهلية السابق فقط إذا تطابقت معرفات المصادر والنسخ غير الفارغة ولم تتغير الحقائق المعروضة. تغير النسخة أو غيابها يستلزم إعادة التحقق، وتُحجب الأسباب والخطوة التالية القديمة. الحقل اختياري لتشغيل التكامل الناقص، لكن لا يمكن الاحتفاظ بتأكيد الأهلية بدونه.

الموقع وطريقة التقديم والحضور حقائق منفصلة. التقديم عبر الإنترنت لا يثبت عدم الحاجة إلى الحضور. التعارض يظهر تحذيرًا وأهلية غير مؤكدة.

## 6. تجربة التطبيق المتصل

احفظ ملفًا، وابحث، وافحص الاستجابة، ثم افتح التفاصيل. اشرح المصادر الداعمة وما بقي مجهولًا. طلب المعلومات الناقصة يجب أن يشير إلى حقول يستطيع المستخدم تعديلها.

```bash
npm run typecheck
npm run build
```

تفحص هذه الأوامر الأنواع وتبني الواجهة. يغطي [سجل التحقق المحلي](../docs/fullstack-verification.md) اتصال المتصفح بالخلفية، وتحتاج جودة التوصيات تقييمًا كاملًا بعد تنفيذ سيرها.

| المشكلة | أول ما تتحقق منه |
|---|---|
| تعذر الاتصال بالخادم | طرفية الخادم وعنوانه في `.env` وإعدادات CORS. |
| البحث غير منفذ | أكمل ملفات المتدرب؛ لا تضف نتائج وهمية في الواجهة. |
| استجابة غير صالحة | قارن JSON بالعقد المتفق عليه. |
| البحث بطيء | افحص النموذج والأدوات وحدود الوقت. |
| اختيار غير موجود | حدّث `choices.ts` عمدًا ووثّق تأثيره على مطابقة البيانات. |

**راجع [الحالة الحالية](../README.ar.md#status) قبل متابعة ربط التطبيق.**
