# فرصة — FURSAH

تطبيق يربط معلومات المستخدم واهتماماته وقيوده بفرص تناسبه، مع أدلة تفسّر التوصيات. يجمع هذا المجلد الواجهة والخلفية والبيانات والتجارب، والقرارات التي اتخذناها أثناء البناء.

**أين وصلنا؟** الاسترجاع الدلالي المحلي يعمل على عينة صغيرة موثقة. الواجهة تصل إلى API، وتنفيذ سير التوصية والتفاصيل داخل التطبيق هو العمل القادم.

<a id="start"></a>
## ابدأ التشغيل

نفّذ الأوامر من `fursah-fullstack/`. تستخدم السكربتات الحالية PowerShell على Windows، وPython 3.11، وNode.js 22 مع npm.

**١. جهّز مكتبات الواجهة والخلفية**

```powershell
.\scripts\setup-fullstack.ps1
```

**٢. شغّل الخلفية في طرفية أولى**

```powershell
.\scripts\start-backend.ps1
```

**٣. شغّل الواجهة في طرفية ثانية**

```powershell
.\scripts\start-frontend.ps1
```

| افتح | العنوان | ماذا تتوقع؟ |
|---|---|---|
| الواجهة | [127.0.0.1:5173](http://127.0.0.1:5173) | الملف الشخصي والقيود ونموذج البحث |
| توثيق API | [127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) | أشكال الطلبات والاستجابات |
| عمل الخدمة | [127.0.0.1:8000/health](http://127.0.0.1:8000/health) | الرمز 200 |
| جاهزية التطبيق | [127.0.0.1:8000/ready](http://127.0.0.1:8000/ready) | الرمز 503 حتى يكتمل ربط التخزين وسير التوصية |

توقف كل خدمة بـ**Ctrl+C**. هذه الخطوة لا تنزّل نموذج الذكاء الاصطناعي ولا تشغّل قاعدة تجربة الاسترجاع. البحث يعيد حاليًا `FURSAH_NOT_IMPLEMENTED` وتعرض الواجهة هذه الحالة.

```text
fursah-fullstack/
├── README.md / README.ar.md
```

<a id="status"></a>
## الحالة الحالية

آخر مراجعة: **١٦ أكتوبر ٢٠٢٦**.

| الجزء | الحالة | الدليل أو العمل القادم |
|---|---|---|
| اتصال الواجهة والخلفية | تحققنا منه محليًا | [سجل التحقق](docs/fullstack-verification.md) |
| الأدلة الخام | ١٬٠٠٠ إعلان خيالي متاح | [دليل البيانات](data/README.ar.md) |
| الاسترجاع المحلي | اكتملت تجربة أربع فرص وثمانية طلبات | [مراجعة النتائج](results/retrieval-review.md) |
| الطلبات خارج موضوعات العينة | البحث يرجع جيرانًا رغم عدم المناسبة | توسيع التقييم وتنفيذ فحص الصلة وسياسة الامتناع |
| القيود والأهلية | صممناها؛ ربطها بالتطبيق قادم | [تصميم البيانات](docs/data-model.md) و[الأدوات](docs/agent-tools.md) |
| البحث والتفاصيل عبر API | العقد موجود والتنفيذ قادم | [دليل الخلفية](backend/README.ar.md) |
| بناء الحاويات وتشغيلها | تحققنا منه عبر GitHub Actions | [فحوص البناء والتشغيل وHTTP](https://github.com/Abdulrazaq3/Fursah-FullStack/actions/runs/38888508034)؛ Docker غير مثبت محليًا |

حققت تجربة الاسترجاع الأولى **Recall@2 = 100% للطلبات الستة ذات الصلة في عينة التطوير**. الطلبان الآخران لا يملكان فرصة مناسبة في العينة. هذه النتيجة لا تثبت جودة البحث على البيانات الكاملة أو جاهزية الإنتاج.

## المكونات الرئيسية

| المسؤولية | الاختيار الحالي |
|---|---|
| الواجهة | React وTypeScript وVite |
| API والتحقق من شكل البيانات | FastAPI وPydantic |
| تجربة Embeddings المحلية | BGE-M3 باستخدام SentenceTransformers؛ Dense بأبعاد 1024 |
| التخزين والبحث في التجربة | PostgreSQL مع pgvector؛ بحث دقيق بمقياس Cosine |
| تعريفات النشر | صور منفصلة للواجهة والخلفية، وnginx وDocker Compose |

نموذج الفهم والشرح وإطار تنسيق سير العمل يظلان قرارين لاحقين في تنفيذ التطبيق.
