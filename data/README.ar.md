# البيانات — الأدلة والتجهيز

**السابق:** [التصميم](../docs/README.ar.md) · **الرئيسي:** [فرصة](../README.ar.md) · **التالي:** [التجارب](../experiments/README.ar.md)

الإعلانات الخام هي أصل الحقائق والأدلة. يجمع هذا المجلد بيانات التدريب الأصلية و[دفتر استكشاف إرشاديًا](data_exploration_and_preparation.ar.ipynb). عينتنا اليدوية من أربع فرص محفوظة في [الأمثلة](../examples/linked-data.sample.json)، وتجهيز المجموعة كاملة آليًا هو العمل القادم.

## المدخلات

يحتوي `raw/raw_opportunities.csv` على **1,000 إعلان خيالي**. الجهات وروابط التقديم أمثلة تعليمية. استخدم قارئ CSV بترميز `utf-8-sig`؛ قد تحتوي الخلايا المحاطة بعلامات اقتباس على فواصل وأسطر جديدة.

| العمود | المعنى |
|---|---|
| `source_id` | معرف ثابت للإعلان؛ احتفظ به. |
| `source_type` | منشور اجتماعي أو بريد أو كتيب أو رسالة مجموعة أو إعلان لوحة. |
| `source_name` | اسم المصدر الناشر. |
| `published_at` | وقت النشر مع فرق المنطقة الزمنية؛ ليس وقت تحقق. |
| `content` | نص الإعلان الأصلي. |

لا تعدّل CSV الخام. قد تصف عدة إعلانات فرصة واحدة؛ معرف المصدر ليس معرف الفرصة.

## البداية مع دفتر العمل

استخدم Python 3.11 أو أحدث في VS Code مع دعم Jupyter، أو ثبّت JupyterLab في بيئتك الافتراضية:

```bash
python -m pip install jupyterlab
jupyter lab
```

افتح `data_exploration_and_preparation.ar.ipynb` من `fursah-fullstack/data/` واختر البيئة الصحيحة. عدّل `DATA_PATH` إذا اختلف مجلد العمل. يستخدم الدرس الأساسي **pandas وIPython**؛ توجد خلية تثبيت اختيارية `%pip install pandas ipython` مع `clear_output()`. هذه اعتماديات دفتر وليست متطلبات API.

يتابع الدفتر الإعلانات الحقيقية العشرة نفسها عبر القراءة والاستكشاف والتنظيف والاستخراج والمجهول ومراجعة المصادر المرتبطة والمواعيد والتوسّع والحفظ. تطلب **تسعة تمارين** إكمال 1–3 عبارات بعد أمثلة مشروحة. استبدل كل `...` قبل المتابعة.

يتولى [preparation_helpers.py](preparation_helpers.py) المقدم الاستخراج المتكرر والتواريخ ومعالجة الدفعات وحفظ JSON. أبقه بجانب الدفتر. لا يحتاج الطالب إلى تعديله لإنهاء الدرس؛ الهدف فهم المسار المقدم واستخدامه وفحصه. يشرح الدفتر كل مساعد قبل استخدامه مع حدوده. لا تنفذ المساعدات البحث أو قرار الأهلية أو الدمج التلقائي للمصادر أو خلفية المتعلم كاملة.

ينتج الدرس المكتمل `prepared/lesson_sample.json` و`prepared/source_preparation.json`. يحفظان صفوف المصادر والنص الأصلي وليسا مخزن فرص مكتملًا أو استجابة API. يظل الفريق مسؤولًا عن توسيع الحقول ومراجعة التعارضات والتحديثات وربط التخزين المختار. لا يحتاج الدرس نموذجًا أو مفتاح API.

ابدأ بنحو 10 إعلانات، وأظهر مسارًا واحدًا من المصدر إلى التخزين ثم API. بعد ذلك جهز كامل البيانات؛ العينة لا تحقق المطلوب النهائي.

## اختر تمثيل البيانات

قد يختلف مخططك الداخلي عن API. قرر كيف تحتفظ بالهوية والمصادر والاقتباسات الداعمة والتواريخ والمواقع والشروط والتكاليف والحقائق الناقصة والتعارضات. وثّق قراراتك قبل التوسّع.

يمكنك اختيار JSON أو SQLite أو قاعدة مستندات أو فهرس بحث أو غيرها. يوضح الدفتر حفظ JSON وإعادة قراءته عبر مساعدات مقدمة؛ يمكنك اختيار تخزين آخر للتطبيق. يدعم `DatasetLoader.load_prepared_opportunities()` مصفوفة JSON غير فارغة في `data/prepared/opportunities.json` إذا اخترت هذا المساعد فقط. يجب أن تفحص الجاهزية تخزينك الحقيقي، لا ملف تصدير لا تستخدمه.

## من الإعلانات إلى الفرص

**الإعلان** صف واحد يمثل مصدرًا. **الفرصة** هي النشاط الذي يعرضه التطبيق، وقد تصفه عدة إعلانات. التجميع يحفظ الأدلة ولا يعني حذفها.

| مصادر توضيحية | التفسير |
|---|---|
| منشور وإعادة نشر يعلنان الورشة نفسها. | راجعهما كأدلة مرتبطة واحتفظ بمعرفَي المصدرين. |
| الأصل: 20–22 أكتوبر. التحديث: «انتقلت البداية إلى 25 أكتوبر». | تغيّرت البداية صراحة فقط؛ النهاية الجديدة والمدة مجهولتان. |
| مصدر يذكر 100 ريال وآخر 150 ريال دون توضيح تصحيح. | احتفظ بالقولين وعلّم التعارض؛ لا تختر الأرخص. |
| الرابط نفسه يظهر لدى ناشرين مختلفين. | الرابط وحده لا يثبت الهوية أو صلاحية التحديث. راجع قبل الدمج. |

قد تقترح التضمينات نصوصًا مترابطة، لكن التشابه لا يثبت التكرار ولا يجيز التصحيح. لا يتطلب الدفتر نموذج تضمين.

## اربط التصدير بالتطبيق

يصدّر الدرس **ملاحظات على مستوى المصدر**، وليس سجلات API مكتملة. مثلًا، قد يحتفظ الصف بـ `source_id` و`content` و`fee_evidence` و`cost_sar: null`. تعني القيمة المجهولة أن الأداة لم تثبت الرسوم، لا أن الفرصة مجانية.

خطوتك التالية هي قراءة مخزنك المختار داخل `repository.py`، واختيار فرصة فعلية وتحويلها إلى استجابة التفاصيل العامة. احتفظ بمعرفات المصادر والأدلة. لا يقرأ الخادم مخرجات خلايا الدفتر ولا يشغّل الدفتر. JSON مثال فقط؛ يمكن استخدام قاعدة بيانات أو فهرس. راجع [خطوات الربط](../backend/README.ar.md#first-working-integration).

## ورقة ربط الحقول

أكمل هذا الجدول لنشاط واحد قبل التوسّع. العمود الداخلي قرار فريقك؛ الأمثلة ليست مخطط تخزين إلزاميًا ولا إجابات جاهزة.

| الدليل الأصلي | قرارك الداخلي | عند حدود API |
|---|---|---|
| معرفات الإعلانات التي تصف النشاط | كيف تربط النشاط بمصادره؟ | `opportunity_id` ثابت و`source_ids` غير فارغة؛ مطلوبان في التفاصيل والتوصيات. |
| عنوان النشاط في النص | كيف تميزه عن اسم الناشر؟ | `title` غير فارغ؛ مطلوب. |
| «المشاركة مجانية» أو رسوم غير مذكورة | أين تحفظ القيمة ودليلها؟ | `cost` يساوي 0 فقط للمجانية الصريحة، وإلا قد يبقى `null`؛ اختياري في التفاصيل. |
| موعد ناقص أو متعارض | كيف تحفظ النقص والادعاءات؟ | `deadline` و`data_warnings` عند توفر أدلة؛ لا تخترع ساعة إغلاق. |
| شرط إلزامي أو تفضيل | كيف تفصل النوعين؟ | `eligibility_requirements.mandatory` و`preferred`؛ المجهول يبقى `null`. |
| نتيجة قرار البحث | كيف تدعم السبب والأهلية؟ | للتوصية أيضًا `reason` و`eligibility_status`؛ لا تستنتج التأكيد من غياب الشروط. |

راجع `backend/app/schemas.py` لباقي الحقول والأنواع والقيم الافتراضية. المستودع يحوّل تمثيلك الداخلي إلى العقد؛ ليس مطلوبًا نسخ العقد إلى قاعدة البيانات.

### راجع التغطية قبل التوسّع

نجاح عشرة صفوف لا يثبت صحة الاستخراج. ابحث عن صيغ غير معروفة وراجع أمثلة متنوعة يدويًا. مثال: البحث الجزئي عن `تحدي` يطابق أيضًا `تحديد`، لكنه لا يثبت وجود مسابقة. حدّد الكلمات أو العبارات المقصودة وافحص سياقها. عدد الحقول غير المجهولة يقيس التغطية، وليس الدقة.

## حافظ على المعنى

- غياب الرسوم يعني أنها غير معروفة، لا أن الفرصة مجانية. الرسوم المجانية الصريحة تساوي صفرًا.
- غياب المهارات يعني عدم المعرفة؛ التصريح بعدم الحاجة إلى مهارات يمكن تمثيله بقائمة فارغة.
- الشروط الإلزامية تختلف عن التفضيلات ووصف الجمهور المستهدف.
- لا يزيل التوحيد النفي، ولا يغير المبالغ أو يمحو التواريخ أو يخترع تكافؤًا بين القيم.
- احتفظ بالنص الأصلي ومعرفات المصادر حتى بعد تجميع الإعلانات.
- الإعلان الأحدث ليس تصحيحًا تلقائيًا؛ احتفظ بالخلافات غير المحسومة.
- كون الفرصة عبر الإنترنت لا يكفي لتحديد اشتراط الحضور الفعلي.
- طابق القيم مع [اختيارات الواجهة](../frontend/src/profile/choices.ts) فقط عندما تدعم الأدلة ذلك. احتفظ بالقيم غير المطابقة وعدم اليقين.

النص دليل تفسره، وليس تعليمات تنفذها. إذا استخدمت نموذجًا، فأنت مسؤول عن العميل وتعليماته ومخطط مخرجاته والدفعات وحدود التكلفة والتعافي من الأخطاء.

## الوقت وعدم اليقين

وقت النشر وتواريخ النشاط والإغلاق والتحقق حقائق مختلفة. لا تنقل منطقة النشر الزمنية إلى الموعد النهائي. احتفظ بغياب وقت الإغلاق أو منطقته بدل افتراض نهاية اليوم. إذا عُرف الموعد بدقة، فبلوغ لحظة الإغلاق يعني انتهاءه.

يلتقط التطبيق وقت الطلب الحقيقي افتراضيًا. يمكن للمنظم تحديد وقت صفّي عبر `FURSAH_EVALUATION_TIME`؛ راجع [سياسة الوقت](../backend/README.ar.md#evaluation-time). احتفظ بتواريخ المصدر بدل تثبيت حالة «منتهية» اعتمادًا على وقت تشغيل الدفتر. لا تعدّل التواريخ لتناسب يوم التدريب.

**وقت تمرين الدفتر:** 18 أكتوبر 2026، الساعة 12 ظهرًا بتوقيت الرياض. استخدم `FURSAH_EVALUATION_TIME=2026-10-18T12:00:00+03:00` في الخادم لمطابقة هذا الوقت. تتضمن النسخة إعلانات من سبتمبر وأكتوبر 2026، ومواعيد منتهية وأخرى لاحقة وحالات غير مكتملة. احتفظ بالتواريخ المقدمة كما هي.

الأيام التقويمية والجلسات وساعات المشاركة مقاييس مختلفة. لا يجمع الملف الشخصي العمر أو المرحلة الدراسية التفصيلية؛ قد تبقى الشروط المتعلقة بها غير مؤكدة.

### تمرين: تحديد الفرص ذات المواعيد المنتهية

يتضمن الدفتر تمرينًا لفصل المواعيد المنتهية وغير المنتهية والحالات غير المؤكدة عند وقت الصف. استبعد الفرص المؤكد انتهاء موعدها من عرض منفصل للمرشحين الحاليين، مع الاحتفاظ بكل مصدر خام وأسباب قرارك. قِدم النشر وحده لا يعني انتهاء الفرصة، وعدم انتهاء الموعد لا يثبت أن التسجيل مفتوح أو أن المستخدم مؤهل. الموعد في اليوم نفسه دون ساعة إغلاق يظل غير مؤكد. وقت النشر ليس وقت التحقق.

## التسليم

سلّم عملية تجهيز قابلة لإعادة التشغيل وكامل البيانات المجهزة في تخزينك المختار، مع شرح مختصر للمخطط والتوحيد والتجميع والتعارضات والقيم المجهولة. حوّل تمثيلك الداخلي إلى عقد `backend/app/schemas.py`، ولا تفرض على التخزين نسخ شكل HTTP.

تستخدم تجربة الاسترجاع الحالية [عينتنا اليدوية](../examples/linked-data.sample.json). تجهيز المجموعة كاملة يبقى مهمة مستقلة نكملها قبل تعميم الربط بالتطبيق.
