# Evals · التقييم

هذا هو المكان الوحيد للاختبارات، حالات التقييم، ونتائج التشغيل. **العرض في Phoenix**.

ابدأ من [instrumentation](../backend/app/instrumentation/README.md)، شغّل eval، ثم افتح أثر الطلب ودرجاته في Phoenix.

```powershell
# مرة واحدة، من جذر المشروع
.\.venv\Scripts\python.exe -m pip install -r evals/requirements.txt

# عرض مختصر: 3 حالات فعلية، مع فتح Phoenix
.\evals\run.ps1 -Demo -Open

# مجموعة التطوير كاملة: 12 حالة
.\evals\run.ps1 -Label baseline -Open
```

يفتح Phoenix على http://127.0.0.1:6006؛ اختر مشروع **fursah-eval**. كل حالة تبدأ بـ`eval.case` وتحتها فهم الطلب، embeddings، retrieval، reranking، فحوص المرشحين والاختيار. تظهر درجات المقاييس وسبب الإخفاق على span الحالة ضمن annotations.

العرض المختصر يشمل طلب Excel مجاني، طلبًا يجب أن يرفض التسجيل المغلق، وتعارض القيود. قد تظهر حالات FAIL: هذه نتيجة تقييم حقيقية، وليست عطلًا في Phoenix. رمز الخروج `2` يعني اكتمل التقييم مع إخفاقات جودة. رمز `1` أو `3` يعني مشكلة تشغيل أو قياس.

التقييم يستدعي Gemini الفعلي ويستخدم قاعدة الفرص المحلية. يحتاج إعدادات النموذج، قاعدة البيانات الجاهزة والنماذج المحلية. يبدأ التطبيق داخل عملية التقييم؛ لا يحتاج خادم API آخر. زمن الحالات ثابت لأغراض المقارنة، ولا نعدل `.env`.

| المكان | ما بداخله |
|---|---|
| `cases/` | حالات التطوير والاختبار المستقل وبصمات الملفات |
| `catalog_graders.py` | مقاييس النظام الكامل |
| `grading.py` | شكل الدرجة: اسم المقياس والقيمة والسبب |
| `source_audit.py` | فحص مستقل للأدلة في نص المصدر الأصلي |
| `run.py` | تشغيل المسار الحقيقي، ربط traces وإرسال الدرجات لـPhoenix |
| `runs/<وقت-اسم>/` | `results.jsonl` و`traces.jsonl` و`summary.json` لكل تشغيل |
| `tests/` | اختبارات البرمجة دون استدعاءات للنموذج |
| `checks/` | فحوص التكامل والمتصفح |
| `archive/` | التجارب والنتائج وفحوص النسخ السابقة المحفوظة للرجوع |

```powershell
# فتح Phoenix دون إعادة التقييم
.\evals\phoenix.ps1 -Open

# اختبارات البرمجة
.\evals\test.ps1

# تقييم دون خدمة Phoenix، مع حفظ traces محليًا
.\evals\run.ps1 -Demo -OfflineTraces
```

ملفات Phoenix وقاعدة بياناته في `.local/phoenix/`. التقييم المستقل `cases/holdout.jsonl` يبقى مغلقًا أثناء التطوير؛ لا يشغله أمر العرض. النتائج السابقة موجودة في `archive/runs/` و`archive/reports/`؛ نقل الملفات لا يعني إعادة اعتماد الجودة.

آخر تحقق محلي: **٢١١ اختبار خلفية + ١١ اختبار تجارب نجحت**. عرض Phoenix الفعلي يحوي ٣ طلبات و٩٧ span و٢٩ annotation؛ حالتان PASS وحالة FAIL بسبب التسجيل المغلق. تحققت الواجهة في المتصفح دون أخطاء.

فحوص الواجهة الأولية وعينة الأربع فرص، ومثال تقييم Day 4، موجودة في `archive/checks/` و`archive/starter/` و`archive/cases/`. العرض الحالي يستخدم `cases/dev.jsonl` و`catalog_graders.py`.
