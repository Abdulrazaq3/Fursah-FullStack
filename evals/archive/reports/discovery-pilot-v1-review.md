# مراجعة ربط رحلة البحث — ٢١ أكتوبر ٢٠٢٦

نجحت رحلة اختيارية فعلية تربط المتصفح بـAPI والنماذج المحلية وPostgreSQL وفحوص المصادر والتفاصيل. بقي التشغيل العام معطلًا؛ هذا فحص تركيب على أربع فرص مجهزة، وليس اختبار جودة صلة مستقلًا جديدًا.

| الحد الذي تحققنا منه | الدليل الفعلي | النتيجة |
|---|---|---|
| الواجهة → الطلب | كتابة بحث Excel والضغط على زر الاكتشاف في Edge عبر Playwright | الطلب وصل بعقد الملف والقيود الحالي |
| الطلب → خطة واحدة | تعارض الحضور بين النص والملف | سؤال اختيار قبل أي استدلال |
| الموضوع → قاعدة البيانات | BGE-M3 محلي وCosine على متجهات pgvector الحالية | قراءة الأربع فرص بمصادرها وأدلتها دون كتابة |
| المرشحون → الفحوص | BGE Reranker المحلي ثم الأداة والقيود والأهلية | Excel بقي معاينة غير مؤكدة؛ الشعر لم يفرض جيرانًا |
| التوصية → التفاصيل | فتح التفاصيل من البطاقة | بصمة الأدلة والمصادر متطابقة |
| الحسم → حفظ الملف | الضغط على استخدام قيود النص لهذه المرة | تغير الطلب وبقي localStorage كما هو؛ الميزانية بقيت صفرًا |
| الصياغة غير المدعومة → الواجهة | طلب «الأسبوع الجاي» | خطأ مقروء؛ لم يتحول إلى عدم وجود فرص |
| استجابة API → العرض | أهلية غير مؤكدة وملاحظات مصدر، دون نسبة ملاءمة | لا تأكيد قبول أو فتح تسجيل غير مدعوم |

ثمانية فحوص متصفح نجحت دون أخطاء JavaScript غير معالجة. خمسة طلبات اكتشاف HTTP، منها ثلاثة مرت بالنموذجين فعليًا واثنان حسما مبكرًا، وطلب تفاصيل واحد. أزمنة الطلبات التي شغلت النماذج: 14.55, 14.569, 15.44 ثانية، في قياس محلي محدود لا يمثل الحمل الإنتاجي.

نجح ١٢٢ اختبار خلفية و١١ اختبار تجارب وبناء الواجهة. تشمل الاختبارات الجديدة سؤال المهارة ثم استكمال الإجابة على تحديث مصدر مصطنع، والرفض الصريح للمهارة المطلوبة، ونقص تكلفة المصدر، وانتهاء التسجيل، وتغير الأدلة، وأخطاء النموذج، والتحقق من بقاء قفل العامل بعد انتهاء انتظار HTTP. أسئلة الأهلية المصطنعة ليست نتائج جديدة من البيانات الخام.

التشغيل البارد الأول تجاوز ٩٠ ثانية؛ حفظنا الفشل ونقلنا تجهيز النماذج إلى بدء الخدمة، دون تغيير الدقة أو الأوزان أو العتبات أو تمديد مهلة البحث. طلبات الاستدلال متتابعة ونموذج واحد في الذاكرة. لاحظنا أيضًا طلبًا زائدًا أثناء انشغال العامل؛ أصبح له رمز انشغال مستقل بدل تسميته انتهاء مهلة.

مقاطع تقييم الصلة مطابقة للتجربة السابقة؛ فرق LF وCRLF في مصدر Excel موثق في ربط سياسة التجربة. تقرير المعايرة السابق لم يتغير. لا نستنتج من النجاح أن كل الصياغات أو الموضوعات أصبحت صحيحة؛ نتائج الفقد الدلالي السابقة لا تزال قائمة. كل المصادر خيالية تعليمية، ولم نفحص مواقع جهات حقيقية.

القاعدة بقيت أربع فرص وستة مصادر و٢٤ دليلًا وأربعة متجهات، والخام بقي بالبصمة السابقة. `/ready` يبقى 503، والبحث معطل افتراضيًا خارج التشغيل الاختياري. لم نختبر Docker أو حملًا متعدد المستخدمين لهذه الإضافة.
