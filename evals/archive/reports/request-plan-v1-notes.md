# حد اكتُشف بعد تقرير خطة الطلب الأول

٢٠ أكتوبر ٢٠٢٦: اجتازت الحالات الثلاثون أحكام الدمج والتعارض، لكنها لم تثبت انتقال كل معنى إلى الوحدة التالية. كشف اختبار تركيب جديد أن إزالة موصل «أو» بين الأدوات من النص الدلالي جعل الفاحص اللاحق يقرأ Excel وSQL كشرطين مجتمعين.

حفظنا تقرير الإصدار الأول وبصمته دون استبدال، وأصلحنا الانتقال في `request-plan-v1.1`. بقي موصل البدائل للأدوات، وأزيل فقط موصل البدائل التي صارت فلاتر أنواع أو حضور مستقلة. اختبار التركيب يمر عبر فاحص المتطلبات إلى مرشح SQL وحده، ويؤكد أن Excel أو SQL يكفيه أحدهما.

إعادة الحالات الثلاثين تشخيص بعد الإصلاح، وليست اختبارًا جديدًا لفهم اللغة. [الجولة الأولى](request-plan-v1-review.md) · [مراجعة الإصدار الحالي](request-plan-v1.1-review.md).
